## Retired execution procedure

The command-bearing source, Go-toolchain, archive-extraction, build, test, probe, Manifest, manual-import, and G01 plan blocks from the `6d304935` packet are withdrawn. **This file is not an executable runbook.** It contains no shell setup, build, installer, or live-operation command. Its supported action is read-only review of the linked evidence; do not execute a binary or stage a toolchain by following this document.

This withdrawal addresses the seven current-head P1s at the documentation boundary: there is no path here that checks or executes protected artifacts, opens a PEM, invokes Git or Perl-backed hashing, extracts an archive, builds from a checkout, or launches a process as root. It does **not** prove that the underlying ACL checks, PEM reader, source snapshot, Git configuration, shell environment, or executable artifacts are safe. In particular, the staged-Go finding is not technically rebutted: any future executable procedure must independently verify the complete staged Go distribution against an approved digest or signature **before its first invocation**. Until that and the other findings receive an implemented, isolated reproduction and independent review, no G02/G01 binary procedure is supported here.

If a future separately authorized test needs the manual fallback, use only the same already-identified App and owner-controlled organization installations. Never resolve an ambiguous Manifest attempt by silently creating another App. Do not put a private key in a command argument, environment variable, clipboard, repository, log, or chat. A protected input and a PEM ACL-safe reader must be independently established before any key is opened; this packet does not establish that reader. On timeout, identity mismatch, uncertain cleanup, or storage failure, stop and retain the recovery evidence for the owner rather than retrying, deleting state, or broadening permissions.

Recovery must bind the retained journal to the same attempt and App, including after loss of the original shell. Preserve the original private parent and journal identity; do not substitute a fresh parent, delete the journal, or reset the nonce to make an unresolved attempt appear new. A future reviewed recovery procedure must revalidate that retained state and fail closed on uncertainty. This packet supplies no restart implementation.

The maintainer-selected same-account pilot does not override the repository's trust boundary: same-user workdirs, Keychain, launchd, and file permissions do not isolate hostile code. A system daemon, persistent production credential store, signed release identity, distinct service/job identity, and pre-login startup remain unproven or unimplemented as recorded by issue #2.
